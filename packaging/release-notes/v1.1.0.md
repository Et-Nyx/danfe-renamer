## DANFE Renamer 1.1.0

Mesmo programa da versão 1.0.0, agora aceitando **arrastar e soltar**: você pode
arrastar os PDFs (ou uma pasta) direto para a janela, além dos botões que já
existiam.

### O que mudou
- **Arrastar e soltar**: arraste arquivos ou pastas para a lista do programa. Se
a máquina não tiver o suporte a arrastar, a janela avisa e funciona pelos botões,
como antes.
- **Diagnóstico**: o comando `DANFE_Renamer.exe --diagnostics` mostra versão,
sistema, biblioteca de PDF e se o arrastar está disponível. É o que pedir se algo
não funcionar.
- Nada mais mudou: os nomes gerados, as regras de segurança (originais intocados,
nada sobrescrito, arquivos duvidosos ignorados com o motivo escrito) e o
relatório são iguais aos da 1.0.0.

### Como usar
1. Baixe `DANFE_Renamer_v1.1.0.exe` abaixo (seção **Assets**).
2. Dê dois cliques. Se o Windows mostrar **"O Windows protegeu o seu PC"**,
   clique em **Mais informações** e depois em **Executar assim mesmo** (é normal
   para programas sem assinatura digital).
3. Na janela: **arraste os PDFs ou a pasta**, ou use **Choose PDFs** / **Choose
   Folder**. O idioma pode ser trocado para português no canto superior direito.
4. Clique em **Process Files** e acompanhe a barra de progresso.
5. No fim, clique em **Open output folder**. As cópias renomeadas ficam numa pasta
   nova `DANFE_Renamed`, ao lado da pasta escolhida, dentro de uma subpasta com a
   data e a hora da execução.

### Detalhes técnicos
- Windows 10/11 (64 bits). Não precisa instalar Python nem nada.
- Sem rede, sem telemetria: nada é enviado para lugar nenhum.

### English summary
Same program as 1.0.0, now accepting **drag and drop** of PDF files or folders in
addition to the buttons. If a machine lacks drop support, the window says so and
the buttons work as before. New: `DANFE_Renamer.exe --diagnostics` reports the
version, system, PDF library and whether dropping is available — that report is
what to send when something misbehaves. Renaming rules, safety guarantees and
reports are unchanged from 1.0.0. GPL-3.0-or-later.
SHA-256: `{sha256}`.
