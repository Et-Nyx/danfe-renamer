## DANFE Renamer 1.2.0

Agora você escolhe **qual nome entra no nome do arquivo**: o do **emitente**
(como era até agora) ou o do **destinatário**, que aparece em **RAZÃO SOCIAL**
no bloco DESTINATÁRIO / REMETENTE. A escolha fica guardada para a próxima vez.

### O que mudou
- **Nova opção na janela**, logo abaixo do título: *Nome no arquivo* —
  **Emitente — IDENTIFICAÇÃO DO EMITENTE** ou **Destinatário — RAZÃO SOCIAL**.
  Vale para o lote seguinte; a escolha é lembrada na próxima abertura do
  programa.
- Os dois nomes são sempre lidos do documento. A opção só decide qual deles
  aparece no nome do arquivo; o relatório mostra os dois.
- Se o nome escolhido não estiver impresso no documento, o arquivo é **ignorado
  com o motivo escrito** — nunca é usado o outro nome no lugar.
- **Relatório**: duas colunas novas, `recipient` (destinatário) e `name_source`
  (de qual nome o arquivo foi nomeado).
- **Linha de comando**: `DANFE_Renamer.exe "C:/notas" --name-source destinatario`.
- Conferido nas 459 notas reais: o destinatário lido bate com o XML em **362 de
  362** documentos (em 2 deles o DANFE corta o nome impresso; o programa lê o
  que está impresso).

### Como usar
1. Baixe `DANFE_Renamer_v1.2.0.exe` abaixo (seção **Assets**).
2. Dê dois cliques. Se o Windows mostrar **"O Windows protegeu o seu PC"**,
   clique em **Mais informações** e depois em **Executar assim mesmo** (é normal
   para programas sem assinatura digital).
3. Escolha em **Nome no arquivo** se o nome deve vir do emitente ou do
   destinatário.
4. Na janela: **arraste os PDFs ou a pasta**, ou use **Choose PDFs** / **Choose
   Folder**. O idioma pode ser trocado para português no canto superior direito.
5. Clique em **Process Files** e acompanhe a barra de progresso.
6. No fim, clique em **Open output folder**. As cópias renomeadas ficam numa pasta
   nova `DANFE_Renamed`, ao lado da pasta escolhida, dentro de uma subpasta com a
   data e a hora da execução.

### Detalhes técnicos
- Windows 10/11 (64 bits). Não precisa instalar Python nem nada.
- Sem rede, sem telemetria: nada é enviado para lugar nenhum.
- Originais intocados, nada sobrescrito, arquivo duvidoso ignorado com o motivo
  escrito (as regras de segurança da 1.0.0 continuam iguais).
- Licença GPL-3.0-or-later — código-fonte em https://github.com/Et-Nyx/danfe-renamer

### English summary
You now choose **which company name the file name carries**: the issuer
(`IDENTIFICAÇÃO DO EMITENTE`, the previous behaviour) or the recipient, printed as
`RAZÃO SOCIAL` in the DESTINATÁRIO / REMETENTE block. Both names are always read;
the choice decides which one is used, is remembered between runs, and a document
that does not print the chosen name is skipped with a reason instead of falling
back to the other name. New report columns `recipient` and `name_source`, and a
`--name-source destinatario` command-line flag. Checked against the 459 real
notes: the recipient read agrees with the NF-e XML in 362 of 362 documents.
Safety rules, name pattern and reports are otherwise unchanged from 1.1.0.
GPL-3.0-or-later.
SHA-256: `{sha256}`.
