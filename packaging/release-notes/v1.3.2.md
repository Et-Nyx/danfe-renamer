## DANFE Renamer 1.3.2

Esta versão conserta o que fazia um lote **parecer certo quando não estava**, e
passa a falar português em tudo o que a pessoa lê — inclusive nos relatórios.

### O que mudou
- **A contagem do lote não esconde mais um erro.** Quando um arquivo não era
  processado, a linha que dizia isso podia ficar fora da janela: a lista de
  arquivos empurrava o resumo para baixo e a última linha desaparecia. O resumo
  agora tem espaço garantido; quem cede é a lista, que tem barra de rolagem.
- **"0 ignorados" não aparece mais junto de "Motivos dos arquivos ignorados".**
  Quando o que houve foi um erro, o resumo diz **Motivos dos erros**.
- **Os números concordam com o texto:** "1 erro", "1 ignorado", "1 arquivo
  analisado" — e não "1 erros".
- **O motivo real aparece.** O painel de detalhes passou a mostrar uma linha
  **Causa** com o que a biblioteca ou o Windows respondeu — por exemplo
  `[WinError 32] The process cannot access the file because it is being used by
  another process`. Isso já era registrado, mas não aparecia em lugar nenhum.
- **Tudo em português.** As frases de erro do programa, a coluna **Motivo**, o
  resumo e os três relatórios (CSV, JSON e HTML) saem no idioma escolhido na
  janela.
- **Os relatórios ganharam duas colunas** para que uma máquina nunca precise ler
  uma frase: `failure_code` (código estável, igual em qualquer idioma) e
  `failure_message` (a frase no idioma escolhido). A coluna `reason` continua
  guardando o texto original da biblioteca, para quem for investigar.
- **Uma cópia que falha não deixa arquivo para trás.** Se algo estiver segurando
  o arquivo recém-escrito (antivírus, sincronização), a cópia é tentada de novo
  antes de desistir; e, se ainda falhar, a cópia incompleta é removida. Antes
  disso, podia ficar um PDF de aparência normal na pasta sem que o relatório
  falasse dele.
- O resumo mostra **quanto tempo o lote levou**.

### Como usar
1. Baixe `DANFE_Renamer_v1.3.2.exe` abaixo (seção **Assets**).
2. Dê dois cliques. Se o Windows mostrar **"O Windows protegeu o seu PC"**,
   clique em **Mais informações** e depois em **Executar assim mesmo** (é normal
   para programas sem assinatura digital).
3. Processe o lote normalmente.
4. Confira o resumo: quantos analisados, quantos renomeados, quantos ignorados e
   **quantos erros**. Se houver erro, clique em **Ver detalhes** e leia a linha
   **Causa**.

### Detalhes técnicos
- Windows 10/11 (64 bits). Não precisa instalar Python nem nada.
- Sem rede, sem telemetria: nada é enviado para lugar nenhum.
- As regras de segurança continuam iguais: os arquivos originais nunca são
  modificados, nada é sobrescrito e um arquivo duvidoso é ignorado com o motivo
  escrito. Agora, além disso, uma cópia que falha não deixa resto na pasta.

### English summary
A batch that lost a file could look clean: the list pushed the result block down
and the line counting the errors was the first to leave the window, so "33
analyzed, 32 renamed, 0 skipped" had no line accounting for the 33rd - and the
heading over the reasons talked about *skipped* files. The result block now has
guaranteed room (the scrollable file list yields instead), the heading names what
actually happened (**Why files failed** when there are errors), and every count
agrees with its wording ("1 error", "1 skipped"). The detail pane gained a
**Cause** line carrying what the library or Windows answered - a `[WinError 32]
… being used by another process`, for instance - which was recorded but never
shown. Failure sentences, the **Reason** column, the summary and all three
reports (CSV, JSON, HTML) now come out in the window's language; the reports
gained `failure_code` (stable, same in every language) and `failure_message`
(the sentence in the chosen language) so a machine never has to read a sentence,
while `reason` keeps the library's own words for whoever investigates. A copy
that fails no longer leaves a finished-looking file behind: a write something
else holds is retried before giving up, and a failed attempt is removed, so the
folder holds only files the report accounts for. The summary also reports how
long the batch took. Reading, naming and writing are otherwise unchanged, and the
safety rules are the same: originals are never modified, nothing is overwritten.
