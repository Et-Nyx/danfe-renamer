## DANFE Renamer 1.3.1

A lista de detalhes de um lote deixou de ser só leitura: agora dá para **abrir o
arquivo que falhou**, **mostrar na pasta** e **copiar o nome e o motivo** direto
da janela — inclusive de vários arquivos de uma vez.

### O que mudou
- **Os detalhes de cada arquivo podem ser copiados.** O painel embaixo da lista
  virou texto selecionável: dá para selecionar com o mouse e copiar com Ctrl+C.
- **O motivo do erro aparece primeiro.** Antes ele era a última linha, embaixo de
  uma sequência de campos vazios; agora o painel começa pelo nome do arquivo, pelo
  caminho completo e pelo motivo.
- **Botões e menu de contexto** em cada arquivo da lista:
  - **Abrir arquivo original** — abre o arquivo que falhou; um duplo clique na
    linha faz o mesmo;
  - **Abrir cópia renomeada** — abre a cópia que a execução gerou (só fica
    disponível quando ela existe);
  - **Mostrar na pasta** — abre a pasta com o arquivo selecionado;
  - **Copiar nome**, **Copiar caminho completo** e **Copiar detalhes**.
- **Vários arquivos de uma vez:** selecione quantos quiser e copie os nomes — um
  por linha. Abrir age no arquivo em foco, para não abrir uma janela por arquivo.
- **Arquivo que não está mais lá** é avisado, em vez de o botão não fazer nada.
- A janela de detalhes abre maior e o painel de texto acompanha o tamanho dela.

### Como usar
1. Baixe `DANFE_Renamer_v1.3.1.exe` abaixo (seção **Assets**).
2. Dê dois cliques. Se o Windows mostrar **"O Windows protegeu o seu PC"**,
   clique em **Mais informações** e depois em **Executar assim mesmo** (é normal
   para programas sem assinatura digital).
3. Processe o lote normalmente.
4. Clique em **Ver detalhes**. Clique com o botão direito em qualquer linha para
   abrir o arquivo, mostrá-lo na pasta ou copiar o nome dele.

### Detalhes técnicos
- Windows 10/11 (64 bits). Não precisa instalar Python nem nada.
- Sem rede, sem telemetria: nada é enviado para lugar nenhum.
- As regras de segurança continuam iguais: os arquivos originais nunca são
  modificados, nada é sobrescrito e um arquivo duvidoso é ignorado com o motivo
  escrito.

### English summary
The batch detail list is no longer read-only: the file that failed can be
**opened**, **shown in its folder**, and its name, full path and reason **copied
out of the window** — for several files at once if you like. The pane under the
list is selectable text, and it now leads with the file name, the full path and
the reason, which used to be the last line under a run of empty fields. Each row
offers **Open original file** (a double-click does the same), **Open renamed
copy** (only when the run produced one), **Show in folder**, **Copy name**,
**Copy full path** and **Copy details**, from buttons and from a right-click
menu; Ctrl+C on the list copies the selected names, one per line. A file that is
no longer there is reported instead of leaving a button that does nothing.
Nothing about how files are read, named or written changed, and the safety rules
are the same: originals are never modified and nothing is overwritten.
GPL-3.0-or-later. SHA-256: `{sha256}`.
