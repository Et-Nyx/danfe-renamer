## DANFE Renamer 1.3.0

Agora o programa lê os **XMLs da NF-e e da NFC-e**, gera o **DANFE/DANFCe em
PDF** e já renomeia a cópia — sem precisar converter o XML à mão antes de usar o
renomeador.

### O que mudou
- **XML é a entrada principal.** Na janela, a opção *Arquivos de entrada* fica
  em **XML — converter e renomear** por padrão. Arraste os XMLs ou a pasta.
- **O renomeador de PDFs continua disponível.** Escolha **PDF — apenas
  renomear** para o comportamento anterior, ou **XML + PDF** para ler os dois
  na mesma pasta. A escolha fica guardada para a próxima abertura.
- **Quando o PDF e o XML da mesma nota estão juntos**, o PDF é a cópia usada
  (nada é regerado) e o XML entra como a fonte dos campos do nome, que é mais
  confiável. Se o PDF não puder ser lido, o XML gera a cópia no lugar dele.
- **NF-e (modelo 55) e NFC-e (modelo 65)** são aceitas: a NFC-e vira um DANFCe
  no formato de cupom, com o QR Code do XML.
- **XML sem autorização** é lido com um aviso; XML cancelado ou negado é
  ignorado com o motivo escrito. Nada é inventado.
- **Relatórios** ganharam as colunas `source_type`, `document_model` e
  `generated`, o total `converted_from_xml` no JSON e a linha
  *converted from XML* na janela e na linha de comando.
- **Linha de comando:** `--input xml` (padrão), `--input pdf` (comportamento
  antigo) ou `--input both`.
- As regras de segurança continuam iguais: os arquivos originais nunca são
  modificados, nada é sobrescrito e um arquivo duvidoso é ignorado com o motivo
  escrito.

### Como usar
1. Baixe `DANFE_Renamer_v1.3.0.exe` abaixo (seção **Assets**).
2. Dê dois cliques. Se o Windows mostrar **"O Windows protegeu o seu PC"**,
   clique em **Mais informações** e depois em **Executar assim mesmo** (é normal
   para programas sem assinatura digital).
3. Confirme em **Arquivos de entrada** se deseja XML, PDF ou os dois, e em
   **Nome no arquivo** se o nome deve vir do emitente ou do destinatário.
4. Na janela: **arraste os XMLs/PDFs ou a pasta**, ou use **Choose PDFs** /
   **Choose Folder**. O idioma pode ser trocado para português no canto
   superior direito.
5. Clique em **Process Files**. No fim, clique em **Open output folder**: as
   cópias renomeadas e os relatórios ficam numa pasta nova `DANFE_Renamed`, ao
   lado da pasta escolhida, dentro de uma subpasta com a data e a hora da
   execução.

### Detalhes técnicos
- Windows 10/11 (64 bits). Não precisa instalar Python nem nada.
- Sem rede, sem telemetria: nada é enviado para lugar nenhum.
- A conversão do XML usa o BrazilFiscalReport (LGPL-3.0); avisos de terceiros no
  repositório do projeto.

### English summary
The program now reads **NF-e and NFC-e XMLs**, generates the **DANFE/DANFCe
PDF** itself and renames the copy — no manual conversion step. XML is the
default input, while **PDF — rename only** keeps the previous behaviour and
**XML + PDF** reads both. When a PDF and its XML are in the same batch, the PDF
is the file that gets copied and the XML provides the name fields; if the PDF
cannot be read, the XML generates the copy instead. NF-e (model 55) and NFC-e
(model 65) are supported. Unauthorized XMLs are read with a warning, cancelled
or denied ones are skipped with a reason, and the safety rules are unchanged:
originals are never modified and nothing is ever overwritten. New report
columns `source_type`, `document_model` and `generated`, a
`converted_from_xml` total, and `--input xml|pdf|both` on the command line.
GPL-3.0-or-later. SHA-256: `{sha256}`.
